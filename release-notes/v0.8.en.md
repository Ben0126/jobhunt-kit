- **New: update reminder.** When you open the local app, the program asks GitHub at most once a day whether a newer version exists (the version number only, none of your information). If there is one, a reminder at the top of the page tells you which file to download and how to safely replace only the program. To turn it off, open jobhunt.yaml in your folder with Notepad or TextEdit and change "update_check: true" to "update_check: false". Older folders do not have that line: add update_check: false at the very end of the file.
- The program now reports its version: `jobhunt.exe --version`.
- AGENTS.md, the playbooks and the resume template did not change; a new folder only adds the update_check line in jobhunt.yaml and a paragraph in START-HERE.md. If you already use v0.7, follow "Already using an older version?" below and replace only the program. This is the last time you need to look for a new version yourself.
