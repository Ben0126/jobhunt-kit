- **Desktop shortcut.** You no longer have to open the job-search folder to start the program:
  - Windows 11: right-click "jobhunt" in the folder, then "Show more options", "Send to", "Desktop (create shortcut)". Windows 10: right-click, then "Send to", "Desktop (create shortcut)".
  - Mac: right-click the program whose name starts with "jobhunt-mac", choose "Make Alias", and drag the alias to the Desktop or the Dock (not yet tested on a real Mac).
  - Move only the shortcut or alias. The program itself must stay in the job-search folder; moved on its own, it says the folder is not a job-search folder.
  - In a newly downloaded folder, the "Open the app" section of START-HERE.md has the same steps.
- The repository page and the release page are now in English first; Chinese readers get links to the Chinese notes.
- AGENTS.md, the playbooks and the resume template did not change. If you already use v0.8, the app shows an update reminder; replace only the program as described in "Already using an older version?" below.
