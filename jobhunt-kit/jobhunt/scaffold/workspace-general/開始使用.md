# 開始使用

這個工具叫 jobhunt-kit。這個資料夾是你的求職小幫手：你用聊天的方式跟 AI 說你的經歷，它幫你整理成履歷、教你 104 每一欄怎麼填、陪你準備面試。

你需要：

- 一台 Windows 或 Mac 電腦。
- Claude 付費方案（Pro 或以上）。免費方案不能用 Code 分頁。
- Chrome、Edge 或 Safari 瀏覽器（把履歷存成 PDF 用）。

下面照順序做，一步做完再做下一步。

## 第 1 步：解壓縮，把資料夾放好

1. 你下載到的是一個 .zip 壓縮檔，要先解壓縮：
   - Windows：在檔案上按右鍵 →「全部解壓縮」→「解壓縮」。
   - Mac：直接點兩下。
2. 之後都用解壓縮出來的那個資料夾，不要用 .zip 本身。
3. 把資料夾放在好找的地方，例如「文件」裡面，改名叫「求職」也可以。

之後不要再搬動它。搬了的話，AI 會找不到。

## 第 2 步：安裝 Claude 桌面版

到 https://claude.ai/download 下載 Claude 桌面版，安裝後登入。不用另外安裝其他程式。

## 第 3 步：在 Code 分頁選這個資料夾

1. 打開 Claude 桌面版，點上方的「Code」分頁。
2. 選資料夾（按鈕名稱可能是「Select folder」或資料夾圖示，推定），選第 1 步放好的資料夾。
3. 在對話框輸入「開始」，送出。

AI 會自動讀資料夾裡的規則，不用貼任何東西。

第一次選這個資料夾時，如果跳出「要不要信任這個資料夾」的詢問，選信任（Trust／Yes）。不信任的話，AI 沒辦法自己幫你打開做好的履歷檔。

畫面上的按鈕名稱和位置可能和這裡寫的不同（推定，待確認），找意思相近的就可以。

## 第 4 步：跟 AI 聊

第一次用時，AI 會先用一小段話說明它會做什麼、你的資料去了哪裡。接著你可以直接：

- 把舊履歷傳給它（或複製文字貼上），它會一段一段幫你整理；
- Word 舊履歷：放進資料夾裡的 inbox，跟 AI 說「幫我看 inbox 裡的履歷」。放進去之前，先在 Word 把生日、身分證、地址那幾行刪掉再存檔（想留原本那份，就先另存一份再刪）；
- 貼上想投的職缺，它會馬上告訴你適不適合；
- 或跟它說你想找哪一類工作，它會問你做過哪些事：打工、社團、專題、志工、實習都算。

很多問題會直接出現選項讓你用點的。要你說經歷的題目，就打字回答。不想回答的題目，說「跳過」就好。

AI 不會幫你編經歷。每一段經歷它都會拿給你看一張「確認卡」。內容沒問題，就點「確認 S-003」（或打字回「確認 S-003」）。只回「好」或「對」不算確認。要改就點「要改」，再打字說哪裡要改。

舊履歷是你自己寫的、內容都正確的話，可以跟 AI 說「舊履歷都正確，直接用」。它會先講一次面試可能被追問的地方，你點「我確認舊履歷內容正確，直接用」（或打「我確認舊履歷內容正確」）之後，就照你寫的用，不再一段一段問。AI 自己加的字、改的說法，還是會問你。

幫朋友或家人用：先跟 AI 說你是幫誰用。每張確認卡都要讓本人看過，由本人自己回覆；你代打的話，要照抄本人的原話，例如「她說：確認 S-001」。你自己覺得可以不算。

### 如果跳出「允許嗎？」的視窗

AI 改這個資料夾裡的檔案不會問你。如果它要做別的事（例如打開網頁），可能會跳出詢問：
- 打開你的履歷檔、讀你貼的職缺網頁：可以允許。
- 要登入 104、送出應徵、寄信：拒絕。這些都要你自己做。

## 之後每次回來

打開 Claude 桌面版的 Code 分頁，選同一個資料夾，開新對話說「繼續」。AI 會從資料夾讀到上次的進度。

## 打開介面

資料夾裡有「jobhunt」程式時，可以打開介面：一個在瀏覽器裡的小網頁，用來看投遞進度、檢查履歷並存成 PDF、一欄一欄複製 104 的文字。沒有這個程式也能照上面的方式用。

- Windows：在資料夾裡點兩下「jobhunt」（圖示是程式、類型是「應用程式」的那個）。第一次如果跳出「Windows 已保護您的電腦」，按「其他資訊」→「仍要執行」。
- Mac：點兩下資料夾裡檔名開頭是「jobhunt-mac」的那個程式（只有一個）。如果打不開、說不支援這台電腦，代表下載錯版本：按左上角蘋果選單 →「關於這台 Mac」，有「晶片」寫 Apple 的要下載 Apple 版，「處理器」寫 Intel 的要下載 Intel 版。
- Mac 第一次打開：這個程式沒有付費的蘋果簽章，所以第一次會被擋。較新的 Mac（macOS 15 以後）照這樣做，畫面上的按鈕名稱可能略有不同，找意思相近的按：
  1. 點兩下程式，跳出警告時按「完成」。
  2. 打開「系統設定」→「隱私權與安全性」，往下捲，找到 jobhunt 那一行，按「強制打開」。
  3. 輸入你登入電腦的密碼。
  4. 再點兩下程式，跳出警告時按「強制打開」。之後點兩下就可以直接用。
  
  較舊的 Mac：在程式上按右鍵 →「打開」，跳出警告再按「打開」。
- 打開後會多一個文字視窗（Windows 是黑色的命令視窗，Mac 是「終端機」）。它就是程式本身：用介面的時候不要關掉它，關掉了介面就連不上。用完再關；Mac 關的時候問你要不要「終止」，按「終止」就好。
- 瀏覽器沒有自己打開的話，把那個視窗裡 http://127.0.0.1 開頭的那一行網址，複製到瀏覽器打開。
- 不小心關掉瀏覽器分頁：再點兩下程式，就會重新打開。舊的分頁打不開了就關掉它，用新開的那個。
- 想從桌面一點就打開：幫程式建一個捷徑。
  - Windows 11：在資料夾裡的「jobhunt」（類型是「應用程式」的那個）上按右鍵 →「顯示其他選項」→「傳送到」→「桌面 (建立捷徑)」。Windows 10：按右鍵 →「傳送到」→「桌面 (建立捷徑)」。
  - Mac：在檔名開頭是「jobhunt-mac」的程式上按右鍵 →「製作替身」，再把替身拖到桌面或 Dock（推定，待確認：還沒有在真正的 Mac 上試過）。
  - 捷徑只是一個入口，點它打開的還是求職資料夾裡的那個程式。**程式本身不要搬出求職資料夾，只搬捷徑。** 程式要放在求職資料夾裡才找得到你的資料；單獨搬走再點兩下，會說「這個資料夾看起來不是求職資料夾」。
  - 如果你把整個求職資料夾搬到別的地方，桌面的捷徑可能會失效；失效的話，把它刪掉再重新做一個就好。
- 程式在你的電腦上跑，不會傳你的資料。唯一會連網的是：每天最多一次，問 GitHub 有沒有新版本（只問版本號，不傳任何你的資料）。有新版本時，介面最上面會出現提醒，告訴你怎麼更新。不想要這個提醒：用記事本打開資料夾裡的 jobhunt.yaml，找到「update_check: true」那一行，把 true 改成 false，存檔。如果找不到這一行（舊版資料夾沒有），就在檔案最後加一行 update_check: false，存檔。

## 改用 Cowork 的話（備用）

沒有 Code 分頁、或比較習慣 Cowork 時：
1. 在 Claude 桌面版的 Cowork 開一個新工作（一定要用桌面版）。
2. 在這個工作裡按「Add folder」，選這個資料夾。不要用「建立專案 → Use an existing folder」，那樣 AI 只能讀、不能寫，也不會照規則做（已實測）。
3. 用記事本打開資料夾裡的「開場句.txt」，全選、複製，貼進對話框送出。

每次回來都要重做這 3 步。少做一步，AI 會變成一般聊天，不會照規則做。

## 你的資料去了哪裡

資料存在你電腦的資料夾，不會傳到 jobhunt 的任何伺服器；但 AI 讀到的內容會送到你使用的 AI 服務處理（用 Cowork 時，它會在雲端處理它需要的檔案）。

所以：

- 不要把身分證字號、銀行帳號、密碼打給 AI，也不要放進這個資料夾。
- 舊履歷最簡單的做法：打開舊履歷，全選、複製文字，貼給 AI 之前，先把生日、身分證、地址那幾行刪掉。Word 檔放進 inbox 之前也一樣先刪掉。
- 104 截圖只截要填的那一區：Windows 按 Win + Shift + S，Mac 按 Shift + ⌘ + 4，用滑鼠框出那一塊。生日、身分證、地址那一區不要框進去。
- 大頭照不要放進這個資料夾（見下面「大頭照」）。

## 把履歷存成 PDF

有打開介面的話，最簡單是在介面的「履歷」頁按「存成 PDF」：它會先檢查，再直接打開列印視窗，從下面第 4 點開始做。

AI 做好的履歷檔在「resumes」資料夾裡，檔名結尾是 .html。檔名的數字是日期和第幾個職缺，例如 261008-01 是 10 月 8 日的第 1 個；AI 會告訴你是哪一家公司的。

1. 打開履歷檔：
   - Windows：點兩下，它會用瀏覽器打開。
   - Mac：在檔案上按右鍵 →「打開檔案的應用程式」→ Google Chrome。沒有 Chrome 再用 Safari。
2. 先看最上面的黃色提醒。它說超過頁數的話，跟 AI 說，請它刪減。黃色提醒不會印出來。
3. 按列印：Windows 按 Ctrl + P，Mac 按 ⌘ + P。
4. 照你的瀏覽器設定（瀏覽器右上角有三個點的，是 Chrome 或 Edge）。按鈕名稱可能略有不同（推定，待確認）：
   - Chrome：目的地選「另存為 PDF」。紙張大小選「A4」。展開「更多設定」，取消勾選「頁首和頁尾」。按「儲存」。
   - Edge：印表機選「另存為 PDF」。紙張大小選「A4」。展開「更多設定」，取消勾選「頁首和頁尾」。按「儲存」。
   - Safari：左下角「PDF」選單選「儲存為 PDF」。按「顯示詳細資訊」，紙張大小選「A4」，取消勾選「列印頁首與頁尾」。Safari 的版面可能會跑掉（推定，待確認），存完打開檢查一次，跑掉就改用 Chrome 或 Edge。
5. 存到「下載」資料夾就好，不要存進這個求職資料夾。PDF 裡有你的電話，放在這裡 AI 會讀到。

投美國公司的英文履歷，紙張可以改選「Letter」。AI 做檔案時會提醒你。

存完一定要打開 PDF 看一次：有沒有錯字、有沒有缺頁、有沒有「（姓名）」「（學校）」這種還沒換掉的字、內容是不是都是你真的做過的事。

投出去用 PDF 最穩，在每台電腦打開都長一樣，不會跑版。想自己修改文字、或職缺指定要 Word：在程式的履歷頁按「下載 Word 檔」，用 Word 打開修改。Word 檔裡你自己改的字，程式不會再檢查，請自己確認內容都是真的。

## 大頭照

台灣的中文履歷可以放照片，沒有硬性規定。英文履歷建議不要放。

要放照片時：

1. 先跟 AI 說「履歷要放照片」。它會重做一份有照片格的履歷檔。（如果當初說不放，照片格已經拿掉了，直接放照片也不會出現。）
2. 準備一張直式的證件照，檔案要是 .jpg。手機拍的 .heic 或 .png 不行。
3. 改名前先打開「顯示副檔名」，免得改成 photo.jpg.jpg：
   - Windows：檔案總管 → 上方「檢視」→「顯示」→ 勾選「副檔名」。
   - Mac：Finder →「設定」→「進階」→ 勾選「顯示所有檔案副檔名」。
4. 把照片改名成剛好是「photo.jpg」，放在「下載」資料夾。照片不要放進這個求職資料夾，這樣 AI 就讀不到它。
5. 把 AI 做好的履歷檔（resumes 資料夾裡的 .html）複製一份到「下載」，和照片放在一起。
6. 打開「下載」裡的那份履歷檔，照片就會出現在右上角。再照上面的方法存成 PDF。

沒有照片也沒關係，照片的位置會自動不顯示。

## 卡住了怎麼辦

- AI 說讀不到或寫不進資料夾：在 Code 分頁重新選一次這個資料夾（用 Cowork 的話，在這次工作裡再按一次「Add folder」）。
- AI 好像忘了規則：跟它說「請先完整讀 AGENTS.md 再繼續」。還是不行，開新對話再說「繼續」。
- 對話太長、AI 變慢或變笨：開新對話，說「繼續」。
- 想確認 AI 真的有寫進資料夾：打開資料夾裡的「me」→「stories」，確認過的經歷會一則一個檔案出現在這裡。
- 看到 AI 在讀檔、改檔的訊息（例如「Ran a command」「Edited」）：那是 AI 在存檔，正常。
- AI 要幫你登入 104、幫你按送出或寄信：拒絕它。104 和投遞都要你自己操作。
- AI 給你的檔案（.md 結尾）點兩下打不開：在檔案上按右鍵 → 開啟檔案 → 記事本（Mac：右鍵 → 打開檔案的應用程式 → 文字編輯）。
- 不知道下一步做什麼：直接問「我現在該做什麼？」

資料夾裡有 jobhunt 程式時，AI 會用它檢查數字、用詞、佔位字和 104 字數；沒有程式時，是 AI 自己照規則手動看過。程式看不出意思對不對，投遞之前，請你自己再看一次。

想備份：把整個資料夾複製一份到隨身碟或雲端硬碟。
