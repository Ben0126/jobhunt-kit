# jobhunt-kit：求職小幫手

[English](README.md) | 繁體中文（這一頁）

給各科系的學生和新鮮人。用你本來就在用的 AI（Claude Code 或 Codex），把真實經歷整理成有份量的履歷、看職缺適不適合、教你填 104 或 LinkedIn、陪你準備面試。**它不會幫你編經歷。**

覺得自己「沒什麼經歷」？打工、社團、專題、志工、實習都算。你用聊天的方式說，它一段一段幫你整理，每一句都要你親自確認才會寫進履歷。

一個下載檔就能用三種方式。第一次用的時候選你要找哪裡的工作：

- **台灣**：中文履歷（需要也能做英文版），104 每一欄怎麼填。
- **美國**：一頁的英文履歷、LinkedIn 和 Handshake 的文字、工作簽證（F-1 OPT、CPT）相關問題。
- **兩邊都找**：經歷只整理一次，以英文為主。投台灣的工作需要中文時，再從英文做出中文版，中文的每一句也要你確認。

之後可以加（例如從「台灣」改成「兩邊都找」），不能減。

## 需要什麼

- 一台 Windows 或 Mac 電腦。
- 下面其中一個 AI：
  - **Claude**：付費方案（Pro 或以上），加上 Claude 桌面版（到 <https://claude.ai/download> 下載，安裝後登入）。裡面的「Code」分頁可以讓 Claude 讀寫你電腦裡的某一個資料夾。免費方案沒有這個分頁。
  - **Codex（ChatGPT）**：ChatGPT 或 OpenAI 帳號，加上 Codex 電腦版或命令列。網頁版、手機版的 ChatGPT 讀不到你的資料夾，不能用。
- Chrome、Edge 或 Safari 瀏覽器（把履歷存成 PDF 用）。

不用另外安裝其他程式。

## 怎麼開始

1. **解壓縮**：Windows 在檔案上按右鍵 →「全部解壓縮」→「解壓縮」；Mac 直接點兩下。如果解出來的資料夾裡面還有一個 job-hunt-kit 資料夾，要用裡面這個。判斷方法：點進去看得到「開始使用.md」的，就是對的那一個。把它放在好找的地方（例如「文件」），之後不要再搬動它。
2. **用 AI 打開這個資料夾**：Claude 是點上方的「Code」分頁，再選這個資料夾；Codex 是把這個資料夾當成專案打開。如果跳出「要不要信任這個資料夾」，選信任（Trust／Yes）。
3. **輸入「開始」**，送出。AI 會自己讀資料夾裡的規則。
4. 它會先問一題：**你要找哪裡的工作？美國／台灣／兩邊都找**。回答後，它會裝好對應的規則，接著跟你聊。也可以在資料夾裡 jobhunt 程式的開始畫面選。

之後每次回來：用同一個資料夾，開新對話說「繼續」。

更詳細的說明（存成 PDF、放大頭照、卡住了怎麼辦）都在資料夾裡的 **「開始使用.md」**（用「記事本」就能打開）。畫面上的按鈕名稱可能和這裡寫的不一樣，找意思相近的按就可以。

## 已經在用舊版？怎麼更新

新版本出來時，程式畫面最上面會出現「有新版本」的提醒。按那裡的「一鍵更新」：程式和 AI 規則會換成新版，你的經歷、履歷和投遞進度都不會動。更新到一半失敗的話，程式會自己把舊的檔案放回去。

**千萬不要把整個 zip 直接解壓縮、蓋過你現在用的求職資料夾。** 新 zip 裡的 resume.yaml 和 data/applications.csv 是空白範本，會蓋掉你確認過的經歷和投遞進度。

**v0.9 以前的版本**（分成台灣版 job-hunt-*.zip 和美國版 job-hunt-us-*.zip 兩種下載）不能自己更新到這一版。請照上面「怎麼開始」用新的 zip 另外開一個資料夾；舊的資料夾留著不用動，裡面的東西不會被改或刪掉。

每一版改了什麼，在 Releases 頁面該版本的「What changed」，或 [release-notes 資料夾](release-notes/)裡的 .zh.md 檔（中文）。

## 它會做什麼

- **整理你的經歷**：一段一段問你做了什麼、做得怎樣，整理成一張「確認卡」。你打出卡片代號確認（例如「確認 S-003」）才算數。
- **直接讀舊履歷**：可以複製文字貼上，Word 檔也能放進資料夾裡的 inbox 讓它讀。放之前，先把生日、身分證、地址那幾行刪掉。
- **看職缺適不適合**：貼上想投的職缺，它告訴你適不適合、還缺什麼，再幫你改一份針對這個職缺的履歷。
- **做成履歷檔**：只用你確認過的內容，在瀏覽器存成 PDF，或下載成可以自己改的 Word 檔。台灣的中文履歷可以放大頭照。
- **104 怎麼填**：每一欄寫什麼、字數多少，一欄一欄給你複製。找美國工作的話，LinkedIn 和 Handshake 也一樣。
- **面試準備**：依你的經歷和職缺，陪你練可能被問的問題。
- **jobhunt 程式（可以不用）**：在瀏覽器開一個小頁面，看每家公司投到哪一步、檢查履歷。找美國工作的話，還有美國實習和新鮮人職缺清單，附每家公司公開的 H-1B 申請紀錄；你追蹤的職缺下架時會提醒你。這些公開資料都在你的電腦上讀，不會送出任何關於你的資料。

## 它不做什麼

- **不編經歷。** 履歷上的每一句、每個數字，都要是你真的做過、親自確認過的。
- **不幫你投遞，也不登入 104、LinkedIn 或 Handshake。** 登入、按送出、寄信都要你自己來。AI 要求做這些事時，請拒絕它。

## 你的資料

資料存在你電腦的資料夾，不會傳到 jobhunt 的任何伺服器；但 AI 讀到的內容會送到你使用的 AI 服務處理。

所以不要把身分證字號、銀行帳號、密碼打給 AI，也不要放進這個資料夾。履歷的大頭照由程式另外存在資料夾外面，AI 看不到。

## 第一次打開程式會被擋怎麼辦

資料夾裡的 jobhunt 程式沒有付費簽章，所以第一次打開時，電腦會跳出警告。這是正常的。

**Windows**：跳出「Windows 已保護您的電腦」時，按「其他資訊」→「仍要執行」。

**Mac（macOS 15 以後）**：Mac 的畫面可能和下面寫的不太一樣。卡住的話，在程式上按右鍵 →「打開」，或把畫面截圖（不要截到個人資料）傳給邀請你的人。

1. 點兩下程式，跳出警告時按「完成」。
2. 打開「系統設定」→「隱私權與安全性」，往下捲，找到 jobhunt 那一行，按「強制打開」。
3. 輸入你登入電腦的密碼，再點兩下程式，跳出警告時按「強制打開」。之後點兩下就能直接用。

**較舊的 Mac**：在程式上按右鍵 →「打開」，跳出警告再按「打開」。

不打開這個程式也沒關係，只用 AI 聊天一樣能做履歷。
